# Public exercise instructions

Keep this repository limited to reusable exercises, examples, tests, and instructions. Personal conversations, progress reports, and session logs belong in the private parent workspace.

Use Python 3.13 and C++23. Follow the exercise contract in README.md. Learner files combine runnable examples with numbered TASK prompts. Existing examples must run, while unfinished task tests intentionally fail. Keep task tests independent and preserve stable task names.

For every language refresher, put independent commented examples before the tasks and make the entry point call only examples. Name learner functions `task_XX_description` with full signatures. Begin each task docstring or preceding comment with `TASK X:` and the requested behavior, then a blank line and the placeholder explanation. Keep task objectives ahead of hints. Examples must not call task functions. Use one matching numbered test per task and the standard --examples / --task X commands. Follow native language conventions while preserving this structure for future languages.

Do not commit practice attempts or replace starter code with solutions unless explicitly requested. Maintenance changes must preserve any existing learner edits. Validate solutions in temporary copies. Do not automatically reset files.
